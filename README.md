# Fullstack TP1 - Angular & Next.js

## Run locally
- Angular: `cd ngapp && npm install && npx ng serve` → http://localhost:4200
- Next.js: `cd nxapp && npm install && npm run dev` → http://localhost:3000

## Docker
- `docker run -p 8080:80 marwa05875/ngapp:1.0` → http://localhost:8080
- `docker run -p 3001:3000 marwa05875/nxapp:1.0` → http://localhost:3001
